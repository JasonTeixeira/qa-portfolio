# Production thumbnail system (LOCKED style)

The isometric hybrid, as a repeatable multi-ratio template. Bang out any
thumbnail/cover/short in minutes.

## The two pieces
1. **Hero** — a colorful isometric scene generated by Higgsfield/Recraft V4.1
   (deep-indigo `#131A2E`, vivid friendly palette, code window + annotation).
   Generate at **2k**, per aspect you need (16:9 wide, 9:16 vertical).
2. **Text overlay** — `templates/hybrid-thumb.html`, code-driven (Poppins
   ExtraBold headline + one keyword in a bright highlight box + cloud logo).
   Text is overlaid, never baked → **localizes into all 9 languages.**

## Render any asset
Serve the studio, then open the template with URL params and screenshot at the
ratio's exact pixel size:

```
http://localhost:8790/templates/hybrid-thumb.html
  ?r=16x9            # 16x9 (1280×720) · 9x16 (1080×1920) · 4x5 (1080×1350)
  &hero=/renders/prod/<scene>.png
  &kicker=AI%20ENGINEERING%20%C2%B7%20EXPLAINED
  &title=What%20is%20%3Chl%3ERAG%3C%2Fhl%3E%3F   # <hl> wraps the keyword
  &hl=%23FF6B4A                                   # highlight color
```

Ratios + their sizes are built in; the template lays text out per ratio
(16:9 = left, 9:16 / 4:5 = bottom). Screenshot the page at that size.

## Highlight colors (rotate for variety, stay in-palette)
`#FF6B4A` coral · `#12B5A5` teal · `#FFC94A` yellow · `#5B7CFA` blue · `#3ECF8E` green
