06

The callout voices

Four voices, four hues. A learner should know what kind of sentence is coming before reading it.

Key insight
The cache isn't an optimization — it's a load-shedding contract. Design for the miss, not the hit.
Tradeoff
Fan-out on write makes reads instant and celebrities expensive. Fan-out on read flips it. Pick per user tier.
Failure mode
TTLs expiring together = a stampede. Ten thousand misses hit the primary in the same second. Jitter the TTL.
Capacity math
100M urls/day ≈ 1,160 wps
reads 10:1 → 11.6k rps
×5yr ≈ 180B rows → shard
07

Locked in.

— One hue per component type, everywhere, forever.
— Color at 7% fill / 55% border / 100% ink. Never flood a surface with a hue.
— Diagrams sit on the dot grid; nodes use the anatomy, edges use the grammar.
— Every lesson gets one systems stage; every concept gets one widget rep.
— Fraunces speaks, Hanken explains, JetBrains measures. No fourth voice.
— Motion is transform + opacity + dash offset. Nothing bounces.
— Failure is red and blinking only while it's the point of the lesson.
— No emoji, no stock icons, no gradients louder than the spectrum rail.
