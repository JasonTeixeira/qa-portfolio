# تحسين تكاليف AWS: كيف أحافظ على منصة إنتاجية بأقل من 50 دولارًا شهريًا

يحتوي نظام Nexural البيئي على 185 جدول قاعدة بيانات، و69 نقطة نهاية API، وبيانات سوق فورية، وميزات مدعومة بالذكاء الاصطناعي، ولوحة تحكم حية للجودة. فاتورة AWS الخاصة بي أقل من 50 دولارًا شهريًا.

إليك الطريقة.

## البنية الموفرة للتكاليف

**المبدأ: استخدام الخدمات المُدارة في مستوياتها المجانية/الرخيصة بدلاً من تشغيل بنيتك التحتية الخاصة.**

| الخدمة | الوظيفة | التكلفة الشهرية |
|---------|-------------|-------------|
| Vercel (Hobby → Pro) | استضافة Next.js، دوال الحافة | $0-20 |
| Supabase (Free → Pro) | PostgreSQL، المصادقة، الوقت الفعلي | $0-25 |
| AWS S3 | بيانات القياس، القطع الأثرية | $0.02 |
| AWS Lambda | وكيل API، استيعاب بيانات القياس | $0 (المستوى المجاني) |
| AWS API Gateway | نقطة نهاية HTTP لـ Lambda | $0 (المستوى المجاني) |
| AWS CloudFront | CDN + WAF | $0 (المستوى المجاني) |
| GitHub Actions | CI/CD، المهام المجدولة | $0 (مجاني للمستودعات العامة) |

**الإجمالي: ~$25-45/شهرًا** لمنصة إنتاجية.

## الحيل

### 1. Supabase بدلاً من RDS

مثيل Supabase Pro يكلف 25 دولارًا شهريًا ويتضمن:
- PostgreSQL 15 بسعة تخزين 8 جيجابايت
- أمان على مستوى الصف
- اشتراكات الوقت الفعلي
- مصادقة مدمجة
- نسخ احتياطي تلقائي

مثيل RDS مكافئ (db.t3.micro) يكلف 15 دولارًا شهريًا لكنك تحتاج لإدارة النسخ الاحتياطي والمصادقة والوقت الفعلي بنفسك. أضف تلك الخدمات وستصل إلى 60 دولارًا+.

### 2. Lambda لأحمال العمل المتقطعة

واجهة استيعاب بيانات القياس تتعامل مع 0 طلب معظم الوقت، ثم تنفجر أثناء تشغيل CI. Lambda مثالية: 0 دولار عند الخمول، بنسات أثناء الانفجارات.
