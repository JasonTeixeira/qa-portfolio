# AWS लागत अनुकूलन: मैं एक प्रोडक्शन प्लेटफ़ॉर्म को $50/माह से कम में कैसे चलाता हूँ

Nexural इकोसिस्टम में 185 डेटाबेस टेबल, 69 API एंडपॉइंट, रीयल-टाइम मार्केट डेटा, AI-संचालित सुविधाएँ और एक लाइव क्वालिटी डैशबोर्ड है। मेरा AWS बिल $50/माह से कम है।

यहाँ बताया गया है कैसे।

## वह आर्किटेक्चर जो पैसे बचाता है

**सिद्धांत: अपना खुद का इंफ्रास्ट्रक्चर चलाने के बजाय मैनेज्ड सर्विसेज़ का उनके फ्री/सस्ते टियर पर उपयोग करें।**

| सेवा | यह क्या करती है | मासिक लागत |
|---------|-------------|-------------|
| Vercel (Hobby → Pro) | Next.js होस्टिंग, एज फंक्शन | $0-20 |
| Supabase (Free → Pro) | PostgreSQL, Auth, Real-time | $0-25 |
| AWS S3 | टेलीमेट्री डेटा, आर्टिफैक्ट्स | $0.02 |
| AWS Lambda | API प्रॉक्सी, टेलीमेट्री इंजेशन | $0 (फ्री टियर) |
| AWS API Gateway | Lambda HTTP एंडपॉइंट | $0 (फ्री टियर) |
| AWS CloudFront | CDN + WAF | $0 (फ्री टियर) |
| GitHub Actions | CI/CD, शेड्यूल्ड जॉब्स | $0 (पब्लिक रिपॉजिटरी के लिए फ्री) |

**कुल: ~$25-45/माह** एक प्रोडक्शन प्लेटफ़ॉर्म के लिए।

## ट्रिक्स

### 1. RDS के बजाय Supabase

एक Supabase Pro इंस्टेंस $25/माह है और इसमें शामिल हैं:
- 8GB स्टोरेज के साथ PostgreSQL 15
- रो-लेवल सुरक्षा
- रीयल-टाइम सब्सक्रिप्शन
- बिल्ट-इन ऑथेंटिकेशन
- ऑटो-बैकअप

एक समकक्ष RDS इंस्टेंस (db.t3.micro) $15/माह है लेकिन आपको बैकअप, ऑथ और रीयल-टाइम स्वयं प्रबंधित करने होंगे। उन सेवाओं को जोड़ें और आप $60+ पर पहुँच जाते हैं।

### 2. स्पाइकी वर्कलोड के लिए Lambda

टेलीमेट्री इंजेशन API अधिकांश समय 0 अनुरोधों को संभालता है, फिर CI रन के दौरान बर्स्ट करता है। Lambda इसके लिए परफेक्ट है: निष्क्रिय होने पर $0, बर्स्ट के दौरान पैसे।
