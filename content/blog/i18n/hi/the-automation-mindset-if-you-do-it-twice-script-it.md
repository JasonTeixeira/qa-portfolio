# ऑटोमेशन मानसिकता: अगर दो बार करो, तो स्क्रिप्ट बनाओ

पिछले मंगलवार, मैंने एक डेटाबेस माइग्रेशन चलाया, 3 API endpoints का परीक्षण किया, Stripe webhook लॉग्स चेक किए, CI पाइपलाइन के ग्रीन होने की पुष्टि की, और प्रोडक्शन पर डिप्लॉय किया। कुल समय: 4 मिनट।

पहले इसमें 45 मिनट लगते थे।

अंतर यह नहीं है कि मैं बटन क्लिक करने में तेज़ हो गया हूँ। अंतर यह है कि मैंने बटन क्लिक करना पूरी तरह बंद कर दिया।

## नियम

**अगर मैं कोई काम मैन्युअली दो बार करता हूँ, तो तीसरी बार उसे ऑटोमेट करता हूँ।**

"जब समय मिले" नहीं। "अगले स्प्रिंट" नहीं। तीसरी बार। क्योंकि चौथी बार आने वाली है, और पाँचवीं, और सौवीं।
