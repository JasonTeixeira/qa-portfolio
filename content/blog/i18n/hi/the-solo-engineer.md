# एकल इंजीनियर का टूलकिट: ऐसे उपकरण जो एक टीम की जगह लेते हैं

एक एकल इंजीनियर के रूप में जो प्रोडक्शन सिस्टम बनाता है, मुझे ऐसे उपकरणों की ज़रूरत है जो पूरी टीम की जगह ले सकें: प्रोजेक्ट मैनेजर, QA इंजीनियर, DevOps इंजीनियर, सुरक्षा विश्लेषक और डिज़ाइनर।

यहाँ मेरा वास्तविक टूलकिट है — आदर्श नहीं, बल्कि वह जो मैं रोज़ उपयोग करता हूँ।

## डेवलपमेंट

| उपकरण | किसकी जगह लेता है | क्यों |
|------|----------|------|
| **Claude Code (CLI)** | पेयर प्रोग्रामर | कोड समीक्षा, आर्किटेक्चर चर्चा, डिबगिंग |
| **GitHub Copilot** | जूनियर डेवलपर | बॉयलरप्लेट, टेस्ट जनरेशन, डॉक्यूमेंटेशन |
| **VS Code** | IDE (स्पष्ट रूप से) | एक्सटेंशन: ESLint, Prettier, GitLens, Tailwind |
| **Cursor** | कोड नेविगेशन | जब मुझे बड़े कोडबेस को जल्दी समझना हो |

## ऑपरेशन्स

| उपकरण | किसकी जगह लेता है | क्यों |
|------|----------|------|
| **GitHub Actions** | CI/CD इंजीनियर | पब्लिक रिपॉजिटरी के लिए मुफ़्त, YAML-आधारित, मैट्रिक्स बिल्ड |
| **Vercel** | DevOps टीम | जीरो-कॉन्फिग Next.js डिप्लॉय, प्रीव्यू URL, एनालिटिक्स |
| **Supabase** | डेटाबेस एडमिन | मैनेज्ड Postgres, ऑथ, रियल-टाइम, बैकअप |
| **Better Stack** | ऑन-कॉल इंजीनियर | अपटाइम मॉनिटरिंग, इंसिडेंट अलर्ट, स्टेटस पेज |

## क्वालिटी

| उपकरण | किसकी जगह लेता है | क्यों |
|------|----------|------|
| **Playwright** | QA इंजीनियर | E2E टेस्ट जो CI में चलते हैं, विज़ुअल रिग्रेशन |
| **pytest** | टेस्ट फ्रेमवर्क | फिक्स्चर, पैरामीट्राइज़, प्लगइन इकोसिस्टम |
| **Lighthouse CI** | परफॉरमेंस रिव्यूअर | प्रति डिप्लॉय ऑटोमेटेड परफॉरमेंस बजट |
| **Bandit** | सुरक्षा रिव्यूअर | CI में पायथन सुरक्षा लिंटिंग |

## डिज़ाइन

| उपकरण | किसकी जगह लेता है | क्यों |
|------|----------|------|
| **v0 by Vercel** | UI डिज़ाइनर | विवरण से कंपोनेंट कोड जनरेट करें |
| **Tailwind CSS** | डिज़ाइन सिस्टम | सुसंगत, यूटिलिटी-फर्स्ट, कोई कस्टम CSS ज़रूरी नहीं |
| **Lucide Icons** | आइकन डिज़ाइनर | सुसंगत आइकन सेट, ट्री-शेकेबल |
| **Excalidraw** | डायग्रामिंग टूल | आर्किटेक्चर डायग्राम, डार्क थीम, PNG में एक्सपोर्ट |
