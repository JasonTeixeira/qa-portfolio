# AWS コスト最適化：本番プラットフォームを月50ドル未満で運用する方法

Nexural エコシステムは、185のデータベーステーブル、69のAPIエンドポイント、リアルタイムの市場データ、AI搭載機能、そしてライブ品質ダッシュボードを備えています。私のAWS請求額は月50ドル未満です。

その方法をご紹介します。

## コスト削減を実現するアーキテクチャ

**原則：独自インフラを運用する代わりに、マネージドサービスの無料/低価格帯を活用する。**

| サービス | 機能 | 月額コスト |
|---------|-------------|-------------|
| Vercel (Hobby → Pro) | Next.js ホスティング、Edge Functions | $0-20 |
| Supabase (Free → Pro) | PostgreSQL、認証、リアルタイム機能 | $0-25 |
| AWS S3 | テレメトリデータ、アーティファクト | $0.02 |
| AWS Lambda | APIプロキシ、テレメトリ取り込み | $0（無料枠） |
| AWS API Gateway | Lambda HTTPエンドポイント | $0（無料枠） |
| AWS CloudFront | CDN + WAF | $0（無料枠） |
| GitHub Actions | CI/CD、スケジュールジョブ | $0（パブリックリポジトリは無料） |

**合計：本番プラットフォームで約$25-45/月**

## コツ

### 1. RDSの代わりにSupabase

Supabase Pro インスタンスは月額$25で以下を含みます：
- 8GBストレージのPostgreSQL 15
- 行レベルセキュリティ
- リアルタイムサブスクリプション
- 組み込み認証
- 自動バックアップ

同等のRDSインスタンス（db.t3.micro）は月額$15ですが、バックアップ、認証、リアルタイム機能を自分で管理する必要があります。これらのサービスを追加すると$60以上になります。

### 2. スパイク的なワークロードにはLambda

テレメトリ取り込みAPIはほとんどの場合リクエストが0件で、CI実行中にバースト的に増加します。Lambdaは最適です：アイドル時は$0、バースト時はわずかなコストです。
