# 次に来るエンジニアのために：あなたを超えて生き続けるコード

エンジニアリングの真の評価は、あなたが離れた後に何が起きるかで決まります。誰かが「これ、どう動くの？」とメッセージを送らなければならないなら、あなたは失敗しています。システムは動き続けるべきです。パイプラインはデプロイし続けるべきです。ダッシュボードは更新され続けるべきです。

これこそが、私のエンジニアリング実践において最も意図的に取り組んでいる部分です。つまり、自分の後に来る人のために構築することです。

## テスト

システムが「完成」したと見なす前に、私はこう問いかけます。**「このコードを一度も見たことのない中堅エンジニアが、私に連絡することなく運用できるか？」**

答えが「いいえ」なら、まだ完了していません。コードは動くかもしれませんが、完成ではありません。

## 「運用性」の姿

### 1. 最初の5つの質問に答えるREADME

新しいエンジニアは誰でも同じ5つの質問をします：
1. これは何をするものか？
2. ローカルでどう実行するか？
3. どうデプロイするか？
4. ログはどこにあるか？
5. 壊れた場合、誰に連絡すればよいか？
