# ソロエンジニアのツールキット：チームを代替するツール群

プロダクションシステムを構築するソロエンジニアとして、私はチーム全体を代替するツールを必要としています。プロジェクトマネージャー、QAエンジニア、DevOpsエンジニア、セキュリティアナリスト、デザイナーを。

以下が私の実際のツールキットです。理想論ではなく、日々使っているものです。

## 開発

| ツール | 代替する役割 | 理由 |
|------|----------|-----|
| **Claude Code (CLI)** | ペアプログラマー | コードレビュー、アーキテクチャ議論、デバッグ |
| **GitHub Copilot** | ジュニア開発者 | ボイラープレート、テスト生成、ドキュメント作成 |
| **VS Code** | IDE（当然） | 拡張機能：ESLint、Prettier、GitLens、Tailwind |
| **Cursor** | コードナビゲーション | 大規模コードベースを素早く理解する必要がある場合 |

## 運用

| ツール | 代替する役割 | 理由 |
|------|----------|-----|
| **GitHub Actions** | CI/CDエンジニア | パブリックリポジトリ無料、YAMLベース、マトリックスビルド |
| **Vercel** | DevOpsチーム | 設定不要のNext.jsデプロイ、プレビューURL、分析 |
| **Supabase** | データベース管理者 | マネージドPostgres、認証、リアルタイム、バックアップ |
| **Better Stack** | オンコールエンジニア | アップタイム監視、インシデントアラート、ステータスページ |

## 品質

| ツール | 代替する役割 | 理由 |
|------|----------|-----|
| **Playwright** | QAエンジニア | CIで実行するE2Eテスト、ビジュアルリグレッション |
| **pytest** | テストフレームワーク | フィクスチャ、パラメータ化、プラグインエコシステム |
| **Lighthouse CI** | パフォーマンスレビュアー | デプロイごとの自動パフォーマンス予算 |
| **Bandit** | セキュリティレビュアー | CIでのPythonセキュリティリンティング |

## デザイン

| ツール | 代替する役割 | 理由 |
|------|----------|-----|
| **v0 by Vercel** | UIデザイナー | 説明文からコンポーネントコードを生成 |
| **Tailwind CSS** | デザインシステム | 一貫性、ユーティリティファースト、カスタムCSS不要 |
| **Lucide Icons** | アイコンデザイナー | 一貫したアイコンセット、ツリーシェイク可能 |
| **Excalidraw** | 図作成ツール | アーキテクチャ図、ダークテーマ、PNGエクスポート |

## コミュニケーション

| ツール | 代替する役割 | 理由 |
|------|----------|-----|
| **Loom** | ミーティングファシリテーター | クライアント向け非同期ビデオ更新 |
| **Notion** | プロジェクトマネージャー | ドキュメント、タスク管理、ナレッジベース |
| **Cal.com** | スケジュールアシスタント | ディスカバリーコール用の無料カレンダー予約 |
| **Discord** | チームチャット | コミュニティ管理、ボットテスト |
