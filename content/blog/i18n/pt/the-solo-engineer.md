# O Kit de Ferramentas do Engenheiro Solo: Ferramentas Que Substituem uma Equipe

Como engenheiro solo construindo sistemas de produção, preciso de ferramentas que substituam uma equipe inteira: gerente de projeto, engenheiro de QA, engenheiro DevOps, analista de segurança e designer.

Aqui está meu kit de ferramentas real — não o aspiracional, mas o que uso diariamente.

## Desenvolvimento

| Ferramenta | Substitui | Por quê |
|------|----------|---------|
| **Claude Code (CLI)** | Programador em par | Revisões de código, discussões de arquitetura, depuração |
| **GitHub Copilot** | Desenvolvedor júnior | Código boilerplate, geração de testes, documentação |
| **VS Code** | IDE (obviamente) | Extensões: ESLint, Prettier, GitLens, Tailwind |
| **Cursor** | Navegação de código | Quando preciso entender uma base de código grande rapidamente |

## Operações

| Ferramenta | Substitui | Por quê |
|------|----------|---------|
| **GitHub Actions** | Engenheiro de CI/CD | Gratuito para repositórios públicos, baseado em YAML, builds matriciais |
| **Vercel** | Equipe DevOps | Deploys Next.js com configuração zero, URLs de preview, analytics |
| **Supabase** | Administrador de banco de dados | Postgres gerenciado, autenticação, tempo real, backups |
| **Better Stack** | Engenheiro de plantão | Monitoramento de uptime, alertas de incidentes, páginas de status |

## Qualidade

| Ferramenta | Substitui | Por quê |
|------|----------|---------|
| **Playwright** | Engenheiro de QA | Testes E2E que rodam em CI, regressão visual |
| **pytest** | Framework de testes | Fixtures, parametrização, ecossistema de plugins |
| **Lighthouse CI** | Revisor de desempenho | Orçamentos de desempenho automatizados por deploy |
| **Bandit** | Revisor de segurança | Linting de segurança Python em CI |

## Design

| Ferramenta | Substitui | Por quê |
|------|----------|---------|
| **v0 by Vercel** | Designer de UI | Gera código de componentes a partir de descrições |
| **Tailwind CSS** | Sistema de design | Consistente, utility-first, sem necessidade de CSS personalizado |
| **Lucide Icons** | Designer de ícones | Conjunto de ícones consistente, tree-shakeable |
| **Excalidraw** | Ferramenta de diagramação | Diagramas de arquitetura, tema escuro, exporta para PNG |

## Comunicação

| Ferramenta | Substitui | Por quê |
|------|----------|---------|
| **Loom** | Facilitador de reuniões | Atualizações em vídeo assíncronas para clientes |
| **Notion** | Gerente de projeto | Documentos, rastreamento de tarefas, base de conhecimento |
| **Cal.com** | Assistente de agendamento | Agendamento gratuito de calendário para calls de discovery |
| **Discord** | Chat da equipe | Gerenciamento de comunidade, teste de bots |
