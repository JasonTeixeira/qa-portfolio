# Оптимизация затрат на AWS: Как я удерживаю production-платформу в рамках $50 в месяц

Экосистема Nexural включает 185 таблиц базы данных, 69 API-эндпоинтов, рыночные данные в реальном времени, функции на базе ИИ и живой дашборд качества. Мой счет в AWS — менее $50 в месяц.

Вот как это работает.

## Архитектура, которая экономит деньги

**Принцип: используйте управляемые сервисы на их бесплатных/дешевых тарифах вместо запуска собственной инфраструктуры.**

| Сервис | Что делает | Стоимость в месяц |
|---------|-----------|-------------------|
| Vercel (Hobby → Pro) | Хостинг Next.js, edge-функции | $0-20 |
| Supabase (Free → Pro) | PostgreSQL, Auth, Real-time | $0-25 |
| AWS S3 | Данные телеметрии, артефакты | $0.02 |
| AWS Lambda | API-прокси, прием телеметрии | $0 (бесплатный тариф) |
| AWS API Gateway | HTTP-эндпоинт для Lambda | $0 (бесплатный тариф) |
| AWS CloudFront | CDN + WAF | $0 (бесплатный тариф) |
| GitHub Actions | CI/CD, запланированные задачи | $0 (бесплатно для публичных репозиториев) |

**Итого: ~$25-45/месяц** за production-платформу.

## Хитрости

### 1. Supabase вместо RDS

Экземпляр Supabase Pro стоит $25/месяц и включает:
- PostgreSQL 15 с 8 ГБ хранилища
- Безопасность на уровне строк
- Подписки в реальном времени
- Встроенную аутентификацию
- Автоматические резервные копии

Эквивалентный экземпляр RDS (db.t3.micro) стоит $15/месяц, но вам придется самостоятельно управлять резервным копированием, аутентификацией и real-time. Добавьте эти сервисы — и получите $60+.

### 2. Lambda для пиковых нагрузок

API приема телеметрии большую часть времени обрабатывает 0 запросов, а затем испытывает всплески во время CI-запусков. Lambda идеально подходит: $0 в простое, копейки во время пиков.
