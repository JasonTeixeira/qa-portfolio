# Docker в CI/CD: Паттерны, сократившие время пайплайна на 82%

Мой CI пайплайн раньше занимал 45 минут. Теперь — 8. Самые значительные улучшения дала оптимизация Docker, а не более мощное железо.

## Проблема

Каждый запуск CI выглядел так:
1. Загрузка базового образа (2 мин)
2. Установка системных зависимостей (5 мин)
3. Установка пакетов Python (8 мин)
4. Установка пакетов Node (6 мин)
5. Сборка приложения (4 мин)
6. Запуск тестов (15 мин)
7. Сборка production-образа (5 мин)

Итого: ~45 минут. Разработчики перестали запускать полный пайплайн. Баги начали проскальзывать.
