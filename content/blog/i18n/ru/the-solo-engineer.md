# Инструментарий соло-инженера: Инструменты, заменяющие целую команду

Как соло-инженер, создающий production-системы, мне нужны инструменты, заменяющие целую команду: продакт-менеджера, QA-инженера, DevOps-инженера, аналитика безопасности и дизайнера.

Вот мой реальный инструментарий — не идеальный, а тот, которым я пользуюсь ежедневно.

## Разработка

| Инструмент | Заменяет | Почему |
|------------|----------|--------|
| **Claude Code (CLI)** | Парного программиста | Ревью кода, обсуждение архитектуры, отладка |
| **GitHub Copilot** | Младшего разработчика | Шаблонный код, генерация тестов, документация |
| **VS Code** | IDE (очевидно) | Расширения: ESLint, Prettier, GitLens, Tailwind |
| **Cursor** | Навигацию по коду | Когда нужно быстро разобраться в большой кодовой базе |

## Операции

| Инструмент | Заменяет | Почему |
|------------|----------|--------|
| **GitHub Actions** | CI/CD-инженера | Бесплатно для публичных репозиториев, YAML-конфигурация, матричные сборки |
| **Vercel** | DevOps-команду | Zero-конфигурация для деплоя Next.js, превью-ссылки, аналитика |
| **Supabase** | Администратора БД | Управляемый Postgres, аутентификация, real-time, бэкапы |
| **Better Stack** | Дежурного инженера | Мониторинг доступности, оповещения об инцидентах, статусные страницы |

## Качество

| Инструмент | Заменяет | Почему |
|------------|----------|--------|
| **Playwright** | QA-инженера | E2E-тесты, выполняемые в CI, визуальное регрессионное тестирование |
| **pytest** | Тестовый фреймворк | Фикстуры, параметризация, экосистема плагинов |
| **Lighthouse CI** | Рецензента производительности | Автоматические бюджеты производительности на каждый деплой |
| **Bandit** | Рецензента безопасности | Линтинг безопасности Python в CI |

## Дизайн

| Инструмент | Заменяет | Почему |
|------------|----------|--------|
| **v0 by Vercel** | UI-дизайнера | Генерация кода компонентов по описанию |
| **Tailwind CSS** | Дизайн-систему | Консистентный, utility-first подход, без кастомного CSS |
| **Lucide Icons** | Дизайнера иконок | Единый набор иконок, tree-shakeable |
| **Excalidraw** | Инструмент для диаграмм | Архитектурные диаграммы, тёмная тема, экспорт в PNG |

## Коммуникация

| Инструмент | Заменяет | Почему |
|------------|----------|--------|
| **Loom** | Организатора встреч | Асинхронные видеообновления для клиентов |
| **Notion** | Продакт-менеджера | Документация, отслеживание задач, база знаний |
| **Cal.com** | Ассистента по планированию | Бесплатная запись на звонки для discovery-встреч |
