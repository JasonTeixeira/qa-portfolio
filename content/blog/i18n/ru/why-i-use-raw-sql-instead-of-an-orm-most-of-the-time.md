# Почему я использую чистый SQL вместо ORM (в большинстве случаев)

Это будет спорное заявление, поэтому начну с оговорки: ORM — это нормально. Prisma, SQLAlchemy, Drizzle — все это хорошие инструменты, созданные умными людьми. Я их использую.

Но для платформы Nexural — 185 таблиц, сложные JOIN, материализованные представления, защита на уровне строк — чистый SQL оказался правильным выбором для критических путей. Вот почему.

Я использовал Prisma. Панель управления загружалась за 200 мс локально. В продакшене с реальными данными это заняло 4,2 секунды.
