# 自动化思维：重复两次，就写成脚本

上周二，我执行了一次数据库迁移，测试了3个API端点，检查了Stripe的webhook日志，确认CI流水线通过，然后部署到生产环境。总共用时：4分钟。

过去这需要45分钟。

区别不在于我点按钮的速度变快了，而是我彻底不再点按钮了。

## 规则

**如果某件事我手动做了两次，第三次就把它自动化。**

不是"等我有时间"，也不是"下个迭代"。第三次就做。因为第四次一定会来，第五次也会来，第一百次同样会来。
