## 4. THE FINGERPRINT — "Surface ⇄ System" (now mobile-safe + theatre-proof)

The signature: each piece of work is a polished brand/product **surface** that reveals
the engineered **system** beneath (architecture / schema / the AI pipeline / real
code). Your exact edge — craft on top, machine underneath — made physical.

**Interaction by device:**
- **Desktop:** hover (or scroll-scrub) peels/x-rays the surface to the system.
- **Mobile (required):** tap-to-flip, OR a scroll-scrubbed reveal — NEVER hover-only.
- **Fallback** (item lacks clean system art): a static split composition (surface |
  system) — still on-concept, never broken.

**Taste guardrails (honor the NO-theatre standard):**
- Real architecture/schema/code only — NO fabricated data, NO fake dashboards.
- It's a precise reveal, not a light show. Restraint > spectacle.
- If a real system view doesn't exist for an item, use the static split, don't fake it.

Plus the consistent "instrument" layer: mono metadata, hairline registration ticks,
coordinates, spec-sheet captions framing the artful content.

## 7. SEO & PERFORMANCE BUDGET (don't let "artsy" tank it)

- All content server-rendered / real text in HTML (crawlable) — no client-only canvas
  for primary content. Any shader/generative element is decorative + lazy.
- CWV budget: LCP < 2.5s, INP < 200ms, CLS < 0.1. The fingerprint reveal must not
  block LCP or spike INP.
- Image optimization (AVIF/WebP, explicit dims, lazy below fold).
- Carry the Program A SEO machinery: sitemap (incl. blog), JSON-LD (Org/WebSite/
  Article/CaseStudy/Service/FAQ), breadcrumbs, per-route metadata + OG.
- `clamp()`/`calc()` math MUST have spaces around `+`/`−` (the bug that cost us).

## 9. WHOLE-SITE COHERENCE + LABS → LIVE PORT PLAN

The new direction governs the **entire** site (homepage first, then re-skin work,
services, about, pricing, blog, contact). Porting the design-labs output:
1. Extract its design tokens (type, color, spacing, motion) into the canonical token
   layer (`app/globals.css`).
2. Rebuild as Next.js components reusing the REAL data/routes/backend (checkout, lead
   capture) — port the look, not a fork of the logic.
3. Wire real assets, final copy, JSON-LD, the founder photo, named proof.
4. Re-skin the remaining pages to match (full coherence).
5. Fidelity checklist: hero/showcase pixel parity · fonts loaded · motion +
   reduced-motion · the mobile fingerprint works · 0 console errors · no clamp/
   whitespace bugs.
6. Full gate: build · typecheck · lint (0 errors) · visual regression · axe a11y ·
   Lighthouse/CWV · SEO program · E2E. Then ship.
