# Discord AI OS Final Operating Rhythm And Release Standard

This is the Phase 20 release standard for Sage Ideas Discord, SageBot, RAG, content jobs, learning loops, premium workflows, and growth proof.

## Weekly Operating Loop

1. Review pending applications and approval quality.
2. Nudge approved members stuck before onboarding or first contribution.
3. Route unanswered questions into answers, reviews, or content queue.
4. Approve, reject, or block pending knowledge candidates.
5. Review failed RAG evals and create source-fix tasks.
6. Approve or reject pending content drafts.
7. Retry, resolve, or escalate failed jobs and dead letters.
8. Audit leaderboard anomalies and reverse bad point awards with compensating ledger entries.
9. Review premium requests, SLA, and office-hours queue.
10. Publish approved public proof and track applications from it.

## Monthly Operating Loop

1. Refresh RAG eval questions from real failures and top community questions.
2. Review RAG corpus health and remove stale, private, or weak sources.
3. Update source registry and weekly content themes.
4. Review content conversion from Discord proof to applications.
5. Review member segments, stuck cohorts, and premium leads.
6. Review premium fulfillment quality, SLA, and economics.
7. Archive stale drafts, stale candidates, and low-quality queue items.

## Quarterly Review

1. Re-run scale readiness and failure proof against current table sizes.
2. Re-run security, privacy, permission, and abuse posture review.
3. Review DeepSeek, RAG, job, and dashboard cost posture.
4. Review premium price, margin, fulfillment load, and promise.
5. Review community quality bar, moderation decisions, and channel sprawl.

## Release Gate

Phase 20 is releasable only when:

- The final scorecard validates.
- Every score below 95 has an explicit blocker, owner, and next action.
- Required phase evidence files exist and pass.
- RAG eval passes configured thresholds.
- Discord smoke passes without missing commands or tables.
- Admin Discord dashboard smoke passes where possible.
- Unit tests, typecheck, and production build pass.

The final evidence file is `docs/evidence/discord-ai-os/phase-20-final-scorecard.json`.
