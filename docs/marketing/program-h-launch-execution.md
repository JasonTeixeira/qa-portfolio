## X Thread Drafts

### AI-Native Studio Thread

1. An AI-native studio is not a prompt shop.
2. The useful version builds three layers at the same time: product surface, operating system, growth loop.
3. The surface is what people touch: app, dashboard, checkout, onboarding, diagnostic, course path.
4. The system is what makes it real: data, permissions, evals, cost limits, review queues, observability.
5. The growth loop turns proof into content: screenshots, diagrams, case studies, teardown posts, academy lessons.
6. That is the model behind Sage Ideas.
7. Full breakdown: `/blog/what-an-ai-native-studio-actually-builds`

### AI Audit Thread

1. Most AI projects should start with an audit, not a model.
2. Five questions matter: workflow, data, risk, quality, cost.
3. The audit should name the no-fly zones before code exists.
4. If the system touches money, customers, or trust, it needs review and evals.
5. A good audit ends with four buckets: build now, build later, buy instead, skip.
6. Framework: `/blog/the-ai-implementation-audit-before-you-build`
