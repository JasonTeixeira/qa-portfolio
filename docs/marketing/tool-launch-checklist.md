# Tool Launch Checklist — Program H

Last updated: 2026-06-17

## Pre-Launch

- Confirm tool has one clear promise.
- Confirm no horizontal overflow at 390px.
- Confirm zero console errors.
- Confirm form tracks `lead_magnet_start` and `lead_magnet_complete`.
- Confirm lead capture stores source and attribution metadata.
- Confirm shareable output exists when relevant.
- Confirm schema and sitemap entry exist.
- Confirm blocked/private URL handling is clear.

## Launch Assets

- Landing page URL
- 30-second demo clip
- 1440 screenshot
- Mobile screenshot
- LinkedIn post
- X thread
- Newsletter blurb
- Product Hunt/community post if appropriate
- Outreach email opener

## Launch Channels

- LinkedIn
- X
- GitHub profile/readme link where relevant
- Founder newsletter
- Relevant communities
- Direct outreach to high-fit prospects

## Follow-Up

After 24 hours:

- audit starts
- audit completions
- leads captured
- share reports generated
- badge impressions/referrers
- booked calls

After 7 days:

- search impressions
- indexed status
- top query movement
- best source/medium
- conversion rate by source

## Kill / Iterate Criteria

Iterate if traffic is present but conversion is weak.

Improve distribution if conversion is strong but traffic is weak.

Kill or reposition if neither traffic nor conversion appears after two distribution cycles.
